# Паспорт проекта

> Файл живёт в репозитории: `docs/passport.md`

## 1. Название проекта

Магазин обуви "Sela".

## 2. Проблема

Магазин решил расширяться и открыть онлайн заказы, также это будет удобно для подсчета остатков товаров.

## 3. Пользователи

Клиент магазина — выбирает товар и оформляет заказ; продавец-консультант — ведёт каталог и остатки; администратор — управляет пользователями;

## 4. Цель проекта

Дать клиенту возможность выбрать товар и оформить заказ онлайн, а продавцу — видеть актуальные остатки.

## 5. Метрики успеха

Время оформления заказа < 2 минут;
Клиент находит товар через поиск за < 3 кликов;
Остатки обновляются сразу после продажи, без ручного ввода.

## 6. Границы (что НЕ делаем)

Не подключаем реальные платёжные шлюзы; нет мобильного приложения; доставка курьером не моделируется заказ выдаётся в магазине.

## 7. Риски

Не успеем метрики к дедлайну - приоритизация: сначала каталог и заказ, метрики в конце; сложно придумать 30+ товаров берём реальный ассортимент из открытых источников.
